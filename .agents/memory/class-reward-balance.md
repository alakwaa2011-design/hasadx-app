---
name: Class reward balance
description: Collective class points are an independent balance and ledger, never a bulk student grant or group score.
---

Each teacher class has one collective reward balance with its own immutable history. Adding or deducting class points must never change student balances, student rankings, group scores, or individual reward reports.

**Why:** The teacher uses class points to recognize shared behavior and goals without granting those points to every student individually.

**How to apply:** Keep class operations owner-scoped, idempotent, audited, and nonnegative. Present class points separately in the motivation board. Deduction reasons are optional for both class and student balances.
