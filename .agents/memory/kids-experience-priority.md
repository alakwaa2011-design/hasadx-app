---
name: Kids experience priority
description: Product priority for child-facing Hasaad Kids design and feature work.
---

Hasaad Kids must feel like a joyful, energetic illustrated learning adventure for ages 3–6, not a collection of utility cards or exposed technical flows. Characters, imagery, motion, celebration, and simple play should shape the experience first.

**Why:** The user explicitly rejected an implementation that let sessions, codes, reliability work, and generic interface patterns overshadow the original creative educational vision.

**How to apply:** Keep safety, persistence, permissions, and reliability behind the scenes. Evaluate every child-facing screen by whether a young child sees an inviting world, an obvious playful action, and satisfying encouragement.
