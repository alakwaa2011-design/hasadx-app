---
name: Published saved-game activities
description: Privacy and discovery rules for reusable live-game activities in the shared Activities Library.
---

Saved game activities remain private unless the teacher explicitly chooses to publish them. Public discovery and cross-teacher loading must require both the shared flag and absence of an admin-hidden flag; ownership-only actions remain restricted to the creator.

**Why:** A reusable game can contain teacher-authored material that must never become public implicitly, while published games need to be loadable by another teacher without granting ownership or deletion/link-management rights.

**How to apply:** Any new game creator that persists through the saved-game activity system must present the same final private/public choice, default to private, and use the shared-library endpoint rather than broadening the owner library query.
