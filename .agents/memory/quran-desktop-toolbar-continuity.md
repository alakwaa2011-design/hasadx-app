---
name: Quran desktop toolbar continuity
description: The intended spacing of the reader's wide-screen navigation and action controls.
---

On desktop, arrange the Mushaf reader controls as one visually continuous RTL row near the width of the reading area. Give the action controls modest, consistent width so the center does not look empty. Keep their text labels visible.

**Why:** The user rejected both a viewport-wide bar with navigation and tools at opposite extremes and a compact centered layout that still read as two separate clusters with unused space between them.

**How to apply:** When changing the desktop header, inspect a wide screenshot rather than inferring balance from flex class names. Keep the mobile header's compact arrangement independent of this wide-screen rule.
