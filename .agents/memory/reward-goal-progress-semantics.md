---
name: Reward goal progress semantics
description: Defines which reward events count toward class and student goals and how live-board fairness stays separate from group competition.
---

Reward goals derive progress from unreversed grant transactions created during the goal period. A class goal includes the class's grants; a student goal includes only that student's grants. Balance adjustments and group-score changes never advance a goal.

**Why:** Goals represent recognized learning progress, while balance corrections are administrative and group points are a separate competitive system. Mixing them would make goals change for reasons unrelated to the learning behavior being reinforced.

**How to apply:** Any report, badge, live board, or child-facing goal display must use the same derived progress rule. Keep group scores on their independent ledger, and choose fairness prompts from weekly unreversed student grants rather than lifetime balances alone.
