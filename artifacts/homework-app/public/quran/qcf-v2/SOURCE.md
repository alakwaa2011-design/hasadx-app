# QCF V2 page fonts

These 604 unmodified WOFF2 page fonts are the official QCF V2 Hafs assets
distributed publicly by Quran Foundation:

https://verses.quran.foundation/fonts/quran/hafs/v2/woff2/

The underlying Mushaf typeface is provided by the King Fahd Glorious Quran
Printing Complex. The files are bundled only to render Quran Foundation's QCF
V2 glyph data with the same Madani Mushaf appearance when the CDN or the user's
internet connection is unavailable. They are not modified or sold separately.

`manifest.json` records the source, exact byte size, and SHA-256 digest of every
bundled file. The application build validates all 604 files against that
manifest.
