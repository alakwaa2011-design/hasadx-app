# مصحف حصاد — تطبيق الجوال

تطبيق Expo / React Native مستقل عن قارئ الويب. تُعرض صفحات مصحف المدينة الأصلية المضمّنة محليًا؛ تُحفظ آخر صفحة والعلامات والمظهر وجلسة الحفظ على الجهاز في AsyncStorage. بيانات الآيات والسور والأجزاء من نسخة qcomplex الموثقة في `data/SOURCE.md` وترخيصها في `data/UPSTREAM-LICENSE`. مصدر الصفحات وإذنها في `assets/pages/SOURCE.md`.

## التشغيل

التطوير: شغّل workflow المهيأ `artifacts/mushaf-hasaad-mobile: expo` وافتح المعاينة أو Expo Go. لا يلزم تسجيل دخول للقراءة، والصفحات والبحث والعلامات تعمل دون إنترنت.

## إعداد نسخة أصلية للنشر لاحقًا

- اضبط `EXPO_PUBLIC_QURAN_API_ORIGIN` على عنوان HTTPS المنشور لخدمة API حصاد لتفعيل القرّاء والتفسير؛ **لا تستخدم عنوان التطوير**. لا يُضمَّن عنوان التطوير في نسخة release.
- اضبط `EXPO_PUBLIC_PRIVACY_URL` على عنوان HTTPS لسياسة الخصوصية.
- اختر معرفات الحزمة الرسمية (iOS bundle identifier وAndroid package)، وهي غير مضبوطة بعد. اضبط التوقيع والمعلومات المطلوبة للمتجر، ثم اختبر على الأجهزة الفعلية. لم ينشر هذا المشروع أي نسخة إنتاجية.
- الصوت والتفسير يحتاجان الإنترنت. لا تُنزّل ملفات التلاوة خفية. تقدير حجم صور المصحف المضمّنة نحو 85MB قبل ضغط حزمة المتجر.

## حدود النسخة

الآيات والكلمات ليست مناطق لمس فوق صور المصحف، إذ إن المصدر المتوفر يحدد علاقة الآية بالصفحة **ولا يحوي إحداثياتها المطبوعة**. استخدم زر «آيات الصفحة» لاختيار الآية. لا تُنشئ إحداثيات تخمينية على نص المصحف. تأكيد البناء الأصلي على iPhone وAndroid واختبار الصوت على الجهاز فعليًا مطلوبان قبل تقديم نسخة متجر.
