أريد إعادة تصميم صفحة "رسائل أولياء الأمور" في منصة حصاد لتصبح صفحة مراسلات احترافية، بسيطة، ومركزة فقط على التواصل مع أولياء الأمور.

مهم جدًا:
- لا تغيّر أي منطق برمجي أو API أو قاعدة بيانات أو وظائف الرسائل الحالية.
- المطلوب إعادة ترتيب وتصميم واجهة الصفحة فقط.
- لا تغيّر Sidebar أو Header الحاليين.
- استخدم ألوان ومتغيرات وهوية حصاد الموجودة أصلًا في المشروع.
- حافظ على RTL وعلى Responsive للموبايل والتابلت.

التصميم الجديد المطلوب:

أولًا: رأس الصفحة
ضع في أعلى محتوى الصفحة:

عنوان واضح:
"رسائل أولياء الأمور"

وصف صغير أسفله:
"تواصل مع أولياء الأمور وتابع الردود بسهولة"

وبجانب العنوان أو أسفله مباشرة حسب عرض الشاشة:
- زر أساسي: "رسالة جديدة"
- زر ثانوي: "رسالة جماعية"

زر "رسالة جديدة" يكون Primary بلون حصاد الأخضر.
زر "رسالة جماعية" يكون Secondary بحد أخضر وخلفية فاتحة.

مهم:
احذف أي تكرار لعنوان "رسائل أولياء الأمور" داخل الصفحة.
يظهر العنوان مرة واحدة فقط.

ثانيًا: احذف الإحصائيات غير المتعلقة بالرسائل
احذف من هذه الصفحة بطاقات:
- الواجبات
- التسليمات
- الأنشطة

لا أريد أي إحصائيات لا تتعلق بالمراسلات.

إذا كان هناك لاحقًا احتياج لإحصائيات، يمكن أن تكون فقط مرتبطة بالرسائل مثل:
- غير مقروءة
- بانتظار الرد
- إجمالي المحادثات
لكن لا تضفها الآن إلا إذا كانت البيانات موجودة فعليًا في النظام.

ثالثًا: منطقة الرسائل
أنشئ Card رئيسية واحدة كبيرة تحتوي كل تجربة الرسائل.

في أعلى الـ Card:

في الجهة اليمنى:
Tabs:
- الصندوق
- الأرشيف

وفي الجهة الأخرى:
حقل بحث عن الرسائل.

لا تجعل التبويبات والبحث عناصر منفصلة خارج البطاقة.

التبويب النشط:
- واضح باستخدام لون حصاد الأخضر.
- يمكن استخدام خط سفلي أو خلفية خفيفة.
- بدون تصميم ثقيل.

رابعًا: قائمة المحادثات
أسفل التبويبات والبحث:
اعرض قائمة الرسائل أو المحادثات الحالية بنفس الوظائف الموجودة الآن.

إذا كانت هناك رسائل:
كل محادثة تكون Row أو Card بسيطة تعرض:
- اسم ولي الأمر
- اسم الطالب
- آخر رسالة
- وقت آخر رسالة
- حالة القراءة
- مؤشر للرد الجديد إن وجد

لا تغيّر منطق الحالات الحالي.

خامسًا: Empty State
إذا لم توجد رسائل، لا تترك مساحة فارغة كبيرة.

ضع في منتصف منطقة الرسائل Empty State أنيقة تحتوي:

أيقونة مراسلة بسيطة.

العنوان:
"لا توجد رسائل بعد"

الوصف:
"ابدأ بإرسال رسالة إلى ولي أمر أحد طلابك"

زر:
"إرسال أول رسالة"

ويفتح نفس وظيفة "رسالة جديدة".

سادسًا: الشكل العام
أريد التصميم:
- هادئ
- احترافي
- مساحات بيضاء مريحة
- بطاقات بحواف مستديرة مثل تصميم حصاد الحالي
- ظلال خفيفة جدًا فقط
- بدون زخارف كثيرة
- بدون ألوان جديدة خارج هوية حصاد
- بدون مساحات فارغة مبالغ فيها

رتب الصفحة بحيث يبدو التسلسل البصري هكذا:

[ رسائل أولياء الأمور ]
تواصل مع أولياء الأمور وتابع الردود بسهولة

[ رسالة جديدة ] [ رسالة جماعية ]

على الشاشات الكبيرة:
لا تجعل المحتوى ممتدًا بعرض الصفحة كاملًا إذا تسبب ذلك في فراغات كبيرة.
استخدم max-width مناسب ومتوازن مع الـ Sidebar.

على الموبايل:
- الأزرار يمكن أن تصبح بعرض كامل.
- البحث ينتقل تحت التبويبات إذا لزم.
- قائمة الرسائل تبقى سهلة القراءة.

الهدف النهائي:
تحويل الصفحة من مجموعة عناصر متفرقة إلى Inbox احترافي يشبه تطبيقات المراسلات الحديثة، مع الحفاظ الكامل على هوية حصاد ووظائف النظام الحالية.

نفّذ إعادة التصميم فقط، ولا تغيّر أي منطق أو Backend.
