لا تعِد تصميم منشئ النشاط، ولا تغيّر ترتيب مراحله أو أي وظيفة أو منطق قائم. نفّذ التحسينات الثلاث التالية فقط، ثم اختبرها ولا تنشر.

قيود صارمة

لا تغيّر API أو قاعدة البيانات أو منطق إنشاء ونشر النشاط أو القوالب أو التوليد بالذكاء أو استخراج الملف أو بنك الأسئلة أو الإعدادات أو المكتبة أو النتائج أو النقاط أو الدفع. لا تحذف أي طريقة لإضافة الأسئلة؛ المطلوب فقط تحسين ما يظهر في اللحظة المناسبة.

2. زر القالب في المرحلة الأولى

الخيار الحالي «استخدام قالب جاهز · 4 قوالب» يجب أن يبقى ثانوياً، لكن اجعله واضحاً كإجراء قابل للضغط، لا كنص عادي:

•
اعرضه كزر نصي صغير أو زر Outline خفيف مع أيقونة القوالب.

•
لا تعيده إلى بطاقة كبيرة ولا تضف محتوى جديداً.

•
عند الضغط افتح نفس Dialog أو Sheet القوالب الحالي، من دون تغيير القوالب أو منطقها.

•
بعد اختيار قالب، أبقِ شارة صغيرة: «القالب المختار: [اسم القالب] · تغيير».

3. السؤال الفارغ بحسب طريقة البداية

لا تعرض محرر السؤال الفارغ وخياراته تحت لوحة التوليد أو الرفع أو بنك الأسئلة قبل وصول أي أسئلة. اتبع الحالات التالية:

طريقة البداية
ما يظهر فور الاختيار
يدوي
محرر السؤال الفارغ الحالي.
ذكاء اصطناعي
لوحة التوليد فقط، بلا محرر سؤال فارغ أسفلها.
ملف أو كتاب
واجهة الرفع/الاستخراج فقط، بلا محرر سؤال فارغ أسفلها.
بنك الأسئلة
واجهة الاستيراد فقط، بلا محرر سؤال فارغ أسفلها.




بعد وصول الأسئلة المولدة أو المستخرجة أو المستوردة، اعرضها داخل نفس المحرر الحالي بصورة طبيعية. يجب أن تبقى كل إمكانيات الدمج قائمة: تعديل، حذف، تكرار، وزر «+ إضافة سؤال يدوي» لإضافة سؤال جديد، مع بقاء إمكانية توليد أو استخراج أو استيراد أسئلة إضافية إذا كانت موجودة حالياً.

القاعدة: طرق البداية تختار ما يظهر أولاً فقط؛ لا تنشئ أوضاعاً مغلقة ولا تمنع دمج الأسئلة بعد ذلك.

التحقق المطلوب

اختبر الحالات الأربع على الجوال وسطح المكتب، وتأكد أن الأيقونات موحدة، وزر القالب واضح لكن ثانوي، ولا يظهر سؤال فارغ عند الذكاء أو الملف أو بنك الأسئلة، وتبقى خيارات الدمج كلها متاحة بعد وصول أسئلة فعلية. شغّل Typecheck والاختبارات المناسبة، وأرسل تقريراً بالملفات المعدلة ونتائج التحقق فقط. لا تنشر.
