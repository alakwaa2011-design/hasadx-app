أريد منك تنفيذ فحص قراءة فقط للمصحف الحالي، دون تعديل أي ملف أو تشغيل إصلاحات أو نشر.

أرسل تقريرًا مختصرًا ومنظمًا بالعربية يتضمن:

1. ملفات ومكونات قارئ المصحف الحالية:
- صفحة القارئ الرئيسية.
- مكون الشريط العلوي.
- مكون قائمة الخيارات أو لوحة الأدوات.
- مكون عرض صفحة المصحف.
- مكونات التلاوة والصوت.
- مكونات الكلمات والتفسير والقراء إن وجدت.
- ملفات التنسيق والأنماط المرتبطة بالقارئ.

2. الحالة الحالية للوظائف:
- عرض مصحف المدينة الحقيقي.
- الانتقال بين السور والصفحات والأجزاء.
- الضغط على الآية.
- الضغط على الكلمة.
- التفسير.
- اختيار القارئ.
- تشغيل وإيقاف الصوت.
- تظليل الآية أثناء التلاوة.
- الحفظ أو زر «حفظ».
- التكرار.
- العلامات.
- البحث.
- تغيير حجم المصحف.
- الوضع الداكن أو مظهر القراءة إن وجد.

لكل وظيفة اكتب حالتها بواحدة من:
يعمل / يعمل جزئيًا / لا يعمل / غير موجود / غير مختبر

3. مشاكل الواجهة الحالية:
- ازدحام الشريط العلوي.
- العناصر التي تغطي صفحة المصحف.
- الأيقونات التي لا تحتوي على أسماء واضحة.
- أي تكرار أو خيارات غير ضرورية.
- مشاكل الجوال أو اتجاه RTL.
- أي نصوص أو تسميات تحتاج تغييرًا.

4. اذكر بالتحديد:
- هل توجد لوحة خيارات حالية؟
- كيف تفتح؟
- هل يمكن تحويلها إلى لوحة سفلية Bottom Sheet دون تغيير منطق المصحف؟
- هل توجد تبويبات أو مكونات يمكن إعادة استخدامها لتقسيمها إلى:
  القراءة / الاستماع / الحفظ؟
- هل زر «حفظني» مرتبط بوظيفة فعلية؟ وما اسم الوظيفة البرمجية المرتبطة به؟
- هل زر القائمة الحالي يفتح شيئًا أم هو شكلي فقط؟

5. اقترح خطة واجهة فقط من ثلاث مراحل:
المرحلة الأولى: الشريط العلوي الهادئ.
المرحلة الثانية: لوحة الخيارات السفلية.
المرحلة الثالثة: تنظيم تبويبات القراءة والاستماع والحفظ.

مهم جدًا:
- لا تعدّل الواجهة.
- لا تغيّر API أو قاعدة البيانات أو الصوت أو المصحف أو التلاوة.
- لا تغيّر الأسرار أو البيئة أو المصادقة أو الدفع أو النقاط.
- لا تطبع أي Client Secret أو Access Token أو قيمة سرية.
- لا تنشئ بيانات تجريبية.
- لا تنشر.
- لا تشغّل اختبارات واسعة؛ يكفي فحص الملفات والربط الحالي إن كان آمنًا.

في نهاية التقرير أضف:
- قائمة الملفات التي راجعتها.
- الوظائف التي لم تستطع التحقق منها.
- أكبر 3 مخاطر قبل إعادة تصميم الواجهة.
- حكم واضح: هل يمكن تنفيذ التصميم الجديد بتعديل الواجهة فقط أم يحتاج تعديلًا في المنطق؟
