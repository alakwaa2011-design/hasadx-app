حوّل تجربة Checkout الحالية في حصاد إلى Lemon Squeezy Checkout Overlay الرسمي، بحيث يتم الدفع فوق صفحة حصاد الحالية بدل الانتقال إلى صفحة Checkout خارجية.

مهم:
العمل الحالي صحيح وقد تم التحقق منه، لذلك لا تعِد بناء Checkout ولا تغيّر آلية اختيار الـVariant. ابنِ فوق التنفيذ الحالي فقط.

المطلوب:

1. عند الضغط على زر الاشتراك:
- لا تنتقل إلى صفحة Lemon Squeezy مستقلة.
- افتح Lemon Squeezy Checkout Overlay الرسمي باستخدام Lemon.js فوق صفحة حصاد الحالية.

2. حافظ تمامًا على السلوك الحالي الذي تم إنجازه:
- Basic Monthly يفتح Basic فقط.
- Pro Monthly يفتح Pro فقط.
- Basic Annual يفتح Basic Annual فقط.
- Pro Annual يفتح Pro Annual فقط.
- enabled_variants يجب أن يبقى محصورًا في الـVariant المختار فقط.
- لا تظهر أي باقات أخرى داخل Checkout.

3. استخدم Checkout URL الحالي الذي ينشئه السيرفر، لكن افتحه بالطريقة الرسمية المدعومة كـLemon Squeezy Overlay بدل redirect إلى الصفحة الخارجية.

4. حافظ على:
- Prefill البريد والاسم والبيانات الحالية.
- Card / PayPal / Google Pay وأي وسائل دفع يوفرها Lemon Squeezy.
- إعدادات اللغة والدولة الحالية.
- رابط العودة الحالي عند الحاجة.

5. عند نجاح الدفع:
- استخدم حدث Lemon Squeezy الرسمي Checkout.Success لتحسين تجربة الواجهة فقط.
- أغلق الـOverlay أو اعرض حالة نجاح مناسبة ثم حدّث حالة الاشتراك في الصفحة.
- لا تعتمد على الحدث الأمامي لمنح النقاط أو تفعيل الاشتراك.
- Webhooks الحالية تبقى المصدر الموثوق لتفعيل الاشتراك ومنح النقاط.

6. أضف fallback آمن:
إذا تعذر تحميل Lemon.js أو فتح الـOverlay لأي سبب، افتح Checkout URL الحالي بالطريقة الخارجية الحالية حتى لا تتعطل عملية الدفع.

ممنوع تغيير:
- الأسعار.
- Variant IDs.
- Products أو Variants.
- Webhooks.
- منطق الاشتراكات.
- منطق منح النقاط والتراكم.
- التجديد الشهري أو السنوي.
- قاعدة البيانات.
- تصميم صفحة الباقات.
- enabled_variants الذي تم إصلاحه للتو.

نفّذ أقل تعديل ممكن، وفي طبقة واجهة Checkout فقط.

بعد التنفيذ اختبر الحالات الأربع:
Basic Monthly
Pro Monthly
Basic Annual
Pro Annual

وتأكد في كل حالة من:
1. بقاء المستخدم في صفحة حصاد.
2. فتح Overlay فوق الصفحة.
3. ظهور الباقة المختارة فقط.
4. صحة السعر ودورة الفوترة.
5. إمكانية إغلاق النافذة والعودة للصفحة دون مشكلة.
6. بقاء Checkout الخارجي كـfallback فقط عند فشل الـOverlay.

نفّذ typecheck/build والاختبارات الحالية، ولا تعدّل أي شيء خارج نطاق هذه المهمة.
