أريد تحسين محرر العروض التفاعلية الحالي في HasadX، وليس إعادة بنائه.

مهم جداً:
المحرر الحالي يدعم بالفعل:

* إضافة نص
* تعديل النص
* إضافة صورة
* جلب صورة من الإنترنت
* تحريك العناصر
* تغيير حجمها
* إعدادات للصورة مثل الشفافية والسطوع والتباين والتشبع والتدوير

لذلك لا تعيد بناء نظام النصوص أو الصور من الصفر.

المطلوب الآن هو Phase 1 لتحسين تجربة الصور والعناصر فقط.

========================

1. قص الصور Crop
   ========================

أضف أداة قص احترافية للصورة المحددة.

عند تحديد صورة:
أضف زر واضح في لوحة إعدادات الصورة باسم:
"قص الصورة"

عند الضغط عليه:

* يدخل المستخدم في Crop Mode.
* يظهر إطار قص داخل الصورة.
* يستطيع المستخدم تحريك إطار القص.
* يستطيع تغيير حجم إطار القص.
* يستطيع تطبيق القص.
* يستطيع إلغاء القص.

الأزرار:

* تطبيق القص
* إلغاء

مهم:

* لا تغيّر أبعاد العنصر في الشريحة بطريقة تكسر التخطيط.
* القص يجب أن يظهر فوراً على الصورة.
* احفظ إعدادات القص مع العنصر حتى تظهر بعد إعادة فتح العرض.

احفظ بيانات القص مثلاً:
crop: {
x: number,
y: number,
width: number,
height: number
}

أو استخدم objectPosition/objectFit إذا كان هذا أسهل وآمن.

========================
2. قص داخل الإطار
=================

أضف خيارات للصورة:

* ملء الإطار
* احتواء داخل الإطار
* تمدد
* بلا تغيير

حالياً توجد خيارات مثل:
ملء الإطار / داخل الإطار / تمدد / بلا تغيير

المطلوب:

* تأكد أنها تعمل فعلياً بشكل صحيح.
* اربطها بـ object-fit:
  cover
  contain
  fill
  none

واجعل الاختيار محفوظاً مع العنصر.

========================
3. تحريك الصورة داخل الإطار
===========================

عندما تكون الصورة في وضع "ملء الإطار":
أريد إمكانية تحريك الصورة داخل الإطار بدون تحريك الإطار نفسه.

مثلاً:

* الصورة مقصوصة داخل الكادر.
* المستخدم يستطيع سحب الصورة يمين/يسار/فوق/تحت داخل الإطار.
* هذا يغير object-position أو crop offset.

أضف تحكم بسيط:

* تحريك داخل الإطار
  أو:
* sliders لـ position X و position Y

========================
4. أدوات صورة بسيطة مثل Canva
=============================

في لوحة إعدادات الصورة الحالية:
حسّن الترتيب فقط.

اجعلها مجموعات واضحة:

* ترتيب الطبقات
* ملاءمة الصورة
* تعديل الصورة
* الشفافية
* التدوير

لا تضف أدوات كثيرة.

========================
5. GIF
======

أضف دعم GIF بسيط كعنصر صورة متحركة.

المطلوب:

* يمكن إضافة GIF عبر رابط URL.
* يمكن تحريك GIF وتغيير حجمه مثل الصورة.
* لا تحتاج Giphy API الآن.
* لا تضف بحث Giphy في هذه المرحلة.

أضف زر:
"إضافة GIF"

يفتح input للرابط.
بعد إدخال الرابط:

* يضاف GIF للشريحة.
* يتم حفظه كعنصر type: "gif" أو image مع isGif: true.

========================
6. عناصر تفاعلية لاحقاً
=======================

لا تضف الآن:

* Poll
* Word Cloud
* Drawing
* Konva
* محرر كامل جديد

هذه مرحلة لاحقة.

الآن فقط:

* Crop
* object-fit
* object-position
* GIF URL

========================
7. التوافق مع العروض القديمة
============================

مهم جداً:

* لا تكسر العروض القديمة.
* إذا العنصر لا يحتوي crop أو objectFit استخدم defaults آمنة.
* لا تغيّر schema بطريقة تكسر البيانات القديمة.

Defaults:
objectFit: "cover"
objectPosition: "50% 50%"
crop: undefined

========================
8. العرض للطالب والـ Preview
============================

أي صورة تم قصها أو تعديل object-fit/object-position لها:
يجب أن تظهر بنفس الشكل في:

* Editor
* Preview
* Student View
* Presenter View

بدون ظهور أدوات التحرير.

========================
9. الجودة
=========

* حافظ على RTL.
* حافظ على الأداء.
* لا تضف مكتبات ثقيلة إلا إذا كانت ضرورية جداً.
* لا تعيد بناء المحرر.
* لا تغيّر منطق الذكاء الاصطناعي.
* لا تغيّر توليد الشرائح.
* التعديل فقط على تعامل الصور/GIF داخل المحرر الحالي.

========================
10. التحقق
==========

بعد التنفيذ شغّل:

pnpm --filter @workspace/homework-app run typecheck

ثم:

pnpm --filter @workspace/homework-app run build

وأصلح أي أخطاء.

في النهاية أعطني:

* الملفات المعدلة
* أين يتم حفظ crop/objectFit/objectPosition
* كيف أستخدم قص الصورة
* هل تظهر التعديلات في Preview والطالب
* أي قيود حالية
