التعديل الحالي تحسن بشكل واضح، لكن أريد جولة UI أخيرة على صفحة مكتبة الأنشطة فقط.

لا تغيّر أي منطق أو API أو بيانات أو وظائف. التعديلات التالية بصرية فقط:

1. قسم "رائج الآن":
- البطاقات الحالية كبيرة وطويلة أكثر من اللازم.
- قلل ارتفاعها بشكل واضح.
- أزل الفراغ الأبيض الكبير داخل الجزء السفلي.
- اجعل البطاقة Compact وأقرب للنسبة الموجودة في الصورة المرجعية التي أرسلتها.
- الغلاف يكون العنصر الأساسي.
- أسفل الغلاف يكون العنوان + معلومات مختصرة + زر ابدأ في مساحة صغيرة ومنظمة.
- اجعل البطاقات الثلاث تستفيد من عرض القسم بشكل متوازن.
- لا تجعل ارتفاع "رائج الآن" يستهلك مساحة كبيرة من الشاشة.

2. الفلاتر:
- حاليًا الفلاتر متجمعة ناحية اليمين وتوجد مساحة فارغة كبيرة على اليسار.
- وزع شريط أنواع الأنشطة والفلاتر بشكل متوازن على عرض منطقة المحتوى.
- حافظ على RTL.
- لا تجعل الأزرار تمتد بشكل مبالغ فيه، لكن اجعل التكوين العام متوازنًا بصريًا.

3. بطاقات شبكة الأنشطة:
أعد تصميم Activity Card الحالية بصريًا لتكون أقرب للصورة المرجعية:

الغلاف
ثم العنوان بوضوح وبحد أقصى سطرين
ثم سطر معلومات صغير:
المادة • الصف • عدد الأسئلة
بحسب البيانات المتوفرة فعليًا

ثم سطر أخير:
اسم المنشئ + عدد الاستخدامات

وفي الأسفل:
زر "ابدأ" كزر أساسي أخضر
والإجراءات الثانوية كأيقونات صغيرة.

- لا تجعل البطاقة طويلة.
- استخدم spacing مريحًا.
- اجعل hierarchy المعلومات واضحًا.
- خفف الحدود والظلال.
- استخدم border radius متناسقًا.
- حافظ على ألوان حصاد الحالية.

4. شبكة الأنشطة:
- على Desktop استغل عرض الصفحة بشكل أفضل.
- حافظ على عرض بطاقة مريح للقراءة.
- اجعل المسافات بين البطاقات متساوية.
- استخدم responsive grid مناسب بدل أحجام ثابتة تسبب فراغات.

5. زر "شارك نشاطًا":
مكانه الحالي في أقصى اليسار منفصل بصريًا عن الصفحة.
انقله إلى منطقة عنوان "مكتبة الأنشطة" بحيث يصبح action مرتبطًا بعنوان الصفحة، أو اختر موضعًا أكثر اتزانًا ضمن header الخاص بالمحتوى.

6. لا تغيّر:
- Sidebar الرئيسي
- Header الرئيسي
- البحث أو منطقه
- الفلاتر أو منطقها
- رائج الآن أو طريقة اختيار بياناته
- الحفظ
- النسخ
- التنزيل
- زر ابدأ
- قاعدة البيانات
- API
- Routes

هذه جولة visual polish فقط.

راجع الصورة المرجعية المرفقة سابقًا مرة أخرى، وركز خصوصًا على proportions البطاقات والمساحات والـvisual hierarchy، وليس على نسخ الصورة حرفيًا.

بعد التنفيذ اختبر Desktop وTablet وMobile وشغّل typecheck/build.
