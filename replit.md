# Overview

HasadX (حصادX) is an Arabic RTL educational platform built as a pnpm workspace monorepo. It aims to revolutionize online education by offering smart homework submission, AI-powered auto-grading, and interactive learning experiences. Key features include Kahoot-style quizzes, competitive 3D games, interactive video lessons, and AI assistance for teachers in grading and content generation, all designed to enhance student engagement and streamline educational workflows.

# System Architecture

The project is a pnpm workspace monorepo using Node.js 24, pnpm, and TypeScript 5.9. The backend uses Express 5 with PostgreSQL and Drizzle ORM, validated by Zod. The frontend is a React application with Vite, styled with Tailwind CSS, and uses `wouter` for routing. Session-based authentication is secured with `bcryptjs`. API client code and Zod schemas are generated by Orval from an OpenAPI specification.

**Core Architectural Patterns & Design Decisions:**

-   **Monorepo Structure**: Facilitates shared code and consistent development.
-   **API-First Design**: RESTful API for clear separation of concerns.
-   **Real-time Interactivity**: Socket.IO for live features (games, notifications, whiteboards).
-   **AI Integration**: OpenAI's GPT-5.2 for auto-grading, image-based content analysis, and question generation. Anthropic's Claude Sonnet 4.6 for an AI assistant and AI slide content generation.
-   **Modular Game Engine**: Reusable components and common API for competitive games.
-   **Data Model**: Relational schema supporting teachers, assignments, questions, submissions, students, video lessons, and game data.
-   **UI/UX**: Arabic RTL interface, responsive design with Tailwind CSS, animated components, and accessibility.
-   **Object Storage Integration**: For efficient media content delivery.
-   **Three-Role System**: Supports organizer/teacher, student, and visitor roles with adapted interfaces and authentication.
-   **Pro Design Gating**: Implements a tiered access system for advanced design features (themes, patterns) based on `teachers.has_pro_design` boolean.

**Key Features & Implementations:**

-   **Teacher Authentication & Admin Panel**: Secure, role-based access with a comprehensive dashboard.
-   **Content Sharing**: Teachers can share assignments, question banks, and games.
-   **Assignment & Submission Management**: Supports various question types and submission modes (electronic, AI-analyzed image-based).
-   **Student Management**: Class organization, bulk import (with AI OCR), and class-linked assignments.
-   **Interactive Video Lessons**: Embed questions, and Live Interactive Video Broadcast with real-time teacher control and student feedback.
-   **Adaptive Testing (التمايز / Differentiation)**: IRT-based system with per-question difficulty, skill tracking, level badges, and detailed teacher reports.
-   **Gamification**:
    -   **Live Game Mode ("وميض")**: Kahoot-style real-time quiz.
    -   **3D Competitive Games**: Adventure and Space Race using React Three Fiber.
    -   **Mini-Games**: Flag Quiz, Color Game, Memory Match, Multiplication Table, Scrambled Words (Arabic word bank, PIN sharing), World Capitals Game (multiplayer via Socket.IO), Stroop Effect Game (custom sets, combo multiplier, progressive timer).
    -   **من سيحصد المليون؟ (Who Wants a Million?)**: Millionaire-style quiz with 15 prize levels, lifelines (50/50, AI hint, audience vote, swap question), and a dedicated 360-question bank. Includes a "Team vs Team" mode with real-time Socket.IO interactions, shared PINs, per-team lifelines, and host controls.
-   **Hierarchical Section Organization**: Admin-managed collapsible sections/subsections for activities on the home page.
-   **Teacher Dashboard "Overview" Tab**: Default landing page with welcome banner, live competition launcher, AI smart suggestions, quick actions, recent assignments, top students, and class cards.
-   **AI Assistant ("مساعد حصاد")**: Teacher-only floating chat assistant with daily message limits, conversation history, first-turn caching, and admin monitoring tools.
-   **AI Fill Slide**: Generates slide content (titles, body, bullets, MCQs, captions) based on slide type and presentation context using Claude Sonnet 4.6.
